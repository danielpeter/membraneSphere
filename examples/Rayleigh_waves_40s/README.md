# membrane waves - Rayleigh waves at 40 s

This example simulates Rayleigh waves at 40 s period for a homogeneous phase-velocity map.
It performs multiple simulations where a single receiver is placed at different latitudes.

The simulation input parameters are in file `Parameter_Input`, the wave propagation executable is `bin/propagation`.

To run this example, type:
```
$ ./run_this_example.sh
```

The resulting seismograms for the different receiver locations can all be found in folder OUTPUT/.
These reproduce the seismograms shown in Figure 5.7, page 74, of Carl Tape's master thesis 
[Tape 2003, Waves on a Spherical Membrane](https://sites.google.com/alaska.edu/carltape/home/research/thesis_membrane)
